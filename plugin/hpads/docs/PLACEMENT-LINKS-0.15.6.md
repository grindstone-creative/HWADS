# Playlist revision placement links — 0.15.6

Placement names and IDs in the published playlist revision table now link to the current native placement editor when the viewer can edit that placement. Missing placements and placements outside the viewer's editing permissions remain plain text.

The title, duration and schedule displayed in the revision table still come from the immutable published snapshot. The page explains that links open the current editor; editing a placement does not rewrite the historical revision.

Plugin-only update; no HWADS Box update required.
